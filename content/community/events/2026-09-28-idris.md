The French laboratory IDRIS will host a 3-day formation session aimed at beginners.
The formation will be held from **September 28th to 30th**.

{{< image src="img/events/2026/IDRIS_formation.png">}}

Attendance is free but registration is mandatory and needs to be done on
IDRIS's website: http://www.idris.fr/docs/formations/hpc/formation-kokkos/

## Content

The following subjects will be presented during the formation:
- Kokkos basics
- Getting familiar with Kokkos
- Data containers
- Parallel loops
- Customization of loop policies
- Parallel reductions
- Function annotation
- Atomic operations
- API of Kokkos' algorithms module
- SIMD vectorization with Kokkos
- Debugging and profiling

## Target Audience

This formation will be given in French.

Basic knowledge of the following concepts will be needed in order to follow:
- C++
- CMake
- Linux

This tutorial is not intended for users already fluent in Kokkos.
