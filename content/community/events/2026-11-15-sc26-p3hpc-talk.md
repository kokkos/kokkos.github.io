This paper presents performance improvements for tightly nested multi-dimensional parallelism in the Kokkos library. We show how this can be implemented for GPU and CPU backends, which leads to improved performance and code maintainability. A widely used library like Kokkos needs to be updated in a manner that is friendly to the users and the developers. Using various benchmarks, we show how our work enables Kokkos users to write performance-portable code in a productive manner.
